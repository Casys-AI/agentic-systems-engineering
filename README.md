# Agentic Systems Engineering

Published editions of the three-volume collection by Erwan Lee Pesle, maintained by Casys AI:

- **Agentic Systems Engineering**: An Essay on Delegated Decision Authority
- **Agentic Process Engineering**: A Catalogue of Design Patterns
- **Agentic System Architecture**: A Catalogue of Design Principles

Read the three volumes on [Casys](https://casys.ai/agentic-systems-engineering), or download the PDFs and the web reader from [GitHub Releases](https://github.com/Casys-AI/agentic-systems-engineering/releases).

Each edition has a matching version label in the volumes, release notes and downloadable files. Older editions remain available. This repository contains distribution information; the releases contain the published reading files.
